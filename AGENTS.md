# AGENTS.md

## Tracking work

Use GitHub issues
(https://github.com/xuancongwen/local-dictation-cleanup/issues) to track what
this repository is working on and what it plans next. Don't keep that in
README.md, TODO files, or `.tune/`.

- Open an issue before starting a piece of work. Comment on it with findings
  as you go: `tune.sh` and `test.sh` numbers, candidates tried and rejected,
  and why.
- Close it when the work lands, and reference it from the commit (`Fixes #N`
  or `Refs #N`).
- Record known failures and ideas as open issues, so the plan lives in one
  place.
- Label issues by profile (`profile: max`, and so on; create the label if a
  profile lacks one). Each profile has a pinned tracking issue that lists its
  history and open work (e.g. #8 for `max`). Update it when you open or close
  one of that profile's issues.
